# Доменные data-продукты

| Data product | Домен (BIAN) | Основные данные | Владелец | Потребители |
|---|---|---|---|---|
| **Customer 360** | Клиент (Party Reference Data Directory, Customer Consent, Customer Relationship Management) | Профиль клиента по UCID (признак «клиент RB до слияния»), сегмент, статусы согласий, продукты клиента (счета, вклады, карты, кредиты — количество и остатки), сводка обращений | Data Owner — директор по розничному бизнесу (ФЛ) и директор по МСБ (ЮЛ, ИП). Команда продукта — команда домена «Клиент» (MDM и CRM). Стюард — Data Office | BI, маркетинг (кросс-продажи продуктов FU клиентам RB), риск-менеджмент, контакт-центр (аналитика обращений) |
| **Карты** | Карты (Issued Device Administration, Card Authorization, Card Transaction Capture) | Карты (токен, тип, статус, продукт, держатель по UCID), авторизации, клиринговые операции, агрегаты по клиентам | Data Owner — директор по розничному бизнесу. Команда продукта — команда карточного домена (процессинг). Стюард — операционный департамент (процессинг) | Антифрод, риск-менеджмент (скоринг, поведенческие модели), BI (карточные обороты), маркетинг |
| **Единый продуктовый каталог** | Продукты (Product Directory, Product Design) | Продукты и тарифы FU (версии с периодами действия), маппинг кодов продуктов и тарифов RB → FU, применимость к сегментам | Data Owner — директор по розничному бизнесу (розничные продукты) и директор по МСБ (продукты МСБ). Команда продукта — команда MDM Reference Data. Стюард — Data Office | CRM и каналы продаж, DWH и BI (`dim_product`), риск-менеджмент, финансовый департамент (доходность продуктов) |
| **Кредитный портфель** | Кредиты (Consumer Loan, Mortgage Loan, Corporate Loan, Credit Facility) | Кредиты FU и RB по UCID и единому коду продукта: сумма, ставка, график, задолженность, просрочка (дни, корзины) по единой методике, реструктуризации; ежедневные срезы портфеля | Data Owner — директор по розничному бизнесу (кредиты ФЛ) и директор по МСБ (кредиты ЮЛ, ИП). Команда продукта — команда кредитного домена (Loans). Стюард — риск-менеджмент (кредитное администрирование) | Риск-менеджмент (резервы, PD/LGD, поведенческие модели), финансовый департамент, регуляторная отчётность (DWH), BI, взыскание |
